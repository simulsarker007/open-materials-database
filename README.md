# Open Materials Database: Space Mushroom

A free, open materials database platform where you can find any material.

**Website: https://spacemushroom.com/materials/**

Every property shows its unit, the conditions it was measured under, and the source it came from, with the place in the source where the number appears. When two sources disagree, both values are shown.

## What you can look up

- Stainless steels (304, 316, 316L, 2205, 17-4PH and more)
- Aluminium alloys (6061, 7075, 2024, 5052 and more)
- Titanium alloys (Ti-6Al-4V, Grade 2, Grade 5, Grade 23)
- Nickel alloys, copper alloys, tool steels, cast irons
- Engineering polymers (PEEK, nylon, POM, PTFE, polyimide)
- Technical ceramics, rare earth metals, solders, semiconductors, optical crystals
- Comparison pages such as 304 vs 316 stainless steel and 6061 vs 7075 aluminium

New materials are added every week. The goal is to cover every material humans have discovered.
